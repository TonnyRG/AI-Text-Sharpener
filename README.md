# AI Text Sharpener

Replace blurry text in AI-generated images with crisp vector text.

## Status
v0.1 MVP - 开发中

## Usage
```bash
ai-text-sharpener input.jpg -o output.png --title-font "Microsoft YaHei Bold" --body-font "Microsoft YaHei"
```
