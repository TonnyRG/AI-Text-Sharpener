## 本轮应用

- 保留文档导航—画布—属性的三栏结构。左侧「页面」与「本页文字」使用页签，每种列表都可独立占满可用高度。
- 顶部保留全局导出和撤销；「识别本页 / 批量识别」与「集中复核 / 恢复多色」分组。现有统一导出对话框继续独立选择范围、格式和路径。
- 画布上方为选择移动、添加文字和查看对比；底部为显示框、吸附、缩放和刷新预览。当前工具提供选中态，添加文字可随时返回选择工具。
- 右侧「文字编辑」包含内容、字体与位置；「原图修复」包含擦除框和背景补全，并说明删除区域会恢复原图。
- 离开修复页签即退出橙色框编辑；复核定位自动打开当前页文字列表和文字编辑面板。
- 页签切换不创建历史、不修改项目，支持键盘导航；方向键切换页签不会同时移动文字。
