## 失败模式总结

1. 字号估计偏保守：封面、章节页和数据卡片的大标题/大数字被压小，视觉层级下降。
2. 图表内文字不应自动替换：坐标轴、刻度、公式、图例小字被重绘后反而更差。
3. 图标和徽章误检严重：图标被当成文字擦除或替换，导致空洞、乱码、视觉符号丢失。
4. OCR 后处理对空格和公式不友好：`R Shiny`、`R²`、`AUC > 0.80` 等文本容易变形。
5. 单一字体替换损失风格：原图里的粗细、颜色、卡片层级和英文/中文混排节奏被抹平。
