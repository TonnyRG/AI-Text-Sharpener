使用说明

  1. 左侧「页面」切换幻灯片，「本页文字」查找当前页的文字框；右侧「文字编辑」调整文字，「原图修复」处理原字擦除与背景。
  2. 导入图片，点击「识别本页」或「批量识别」。识别与拟合在本机运行。
  3. 核对识别文字；编辑后会自动更新预览。若想重新贴合原图，再点「自动匹配字体」。
  4. 调整字体、字重、字号、字距与位置；选中绿色文字框，拖动框内移动、拖动四角等比缩放，文字随拖动实时变化。拖动靠近页面中心、边缘或其他文字框时，紫色参考线出现并自动吸附；按住 Alt 临时关闭，或取消「对齐吸附」。方向键可精确微调；在「原图修复」中调整擦除范围时显示橙色框。
  5. 按住「按住看原图」临时查看原图，松开返回；也可使用「滑动对比」检查。复杂图片背景可尝试「纹理局部修复」。
  6. 点击「导出」，选择页面范围和 PPTX、SVG 或 PNG 格式。选择保存文件夹与文件名；全部页面的 SVG / PNG 会按页码打包为 ZIP，同名文件自动编号。左侧「工作区 → 管理」可删除工作区，并在回收站恢复。所有修改自动保存在本机。
  7. 「集中复核」汇总拟合较弱、异常字距、文字相碰等提示。可定位对比、确认无误、保留单处原图或批量保留本页；确认后若再改动，将重新检查。「恢复多色」可处理当前页或全部页面。
  8. Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做；也可点击顶部 ↶ / ↷。输入框编辑、移动、调整 OCR 框、删除及匹配结果均可撤销。每页保留最近 80 步，切换页面、自动保存和导出不会清空；刷新窗口后清空。

此版重点支持水平、单行文字。公式由独立模型检测，先完整保留原图；可识别为 LaTeX 后按二维结构重绘。同一行多色文字可从原图提取，也可选中文字手动着色；复杂艺术字、倾斜文字与混合字体仍需拆分、校正；低置信识别默认保留原图。拟合分数用于比较候选，不是正确率。
