使用说明

  1. 导入图片，在「识别」栏选择「当前页」或「全部页面」。识别与拟合在本机运行。
  2. 核对识别文字；编辑后会自动更新预览。若想重新贴合原图，再点「自动匹配字体」。
  3. 调整字体、字重、字号、字距与位置；选中绿色文字框，拖动框内移动、拖动四角等比缩放，文字随拖动实时变化；橙色框仅在高级擦除范围编辑时显示。
  4. 按住「按住看原图」临时查看原图，松开返回；也可使用「滑动对比」检查。复杂图片背景可尝试「纹理局部修复」。
  5. 点击「导出」，选择页面范围和 PPTX、SVG 或 PNG 格式。选择保存文件夹与文件名；全部页面的 SVG / PNG 会按页码打包为 ZIP，同名文件自动编号。左侧「工作区 → 管理」可删除工作区，并在回收站恢复。所有修改自动保存在本机。
  6. Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做；也可点击顶部 ↶ / ↷。输入框编辑、移动、调整 OCR 框、删除及匹配结果均可撤销。每页保留最近 80 步，切换页面、自动保存和导出不会清空；刷新窗口后清空。

此版重点支持水平、单行文字。公式由独立模型检测，先完整保留原图；可识别为 LaTeX 后按二维结构重绘。复杂艺术字、倾斜文字与同一行多种样式需要手动画框拆分、校正；低置信识别默认保留原图。拟合分数用于比较候选，不是正确率。
